# 01 — Foundations

This module establishes the theoretical, ethical, and legal bedrock of cybersecurity. Before touching a single tool or writing a single script, a security professional must internalize *why* security matters, *who* the stakeholders are, and *what* the rules of engagement are.

---

## Learning Objectives

After completing this module you should be able to:

- Explain the CIA Triad and give a real-world example of each pillar
- Distinguish between White Hat, Grey Hat, and Black Hat hacking
- Summarize the core obligations of GDPR and HIPAA relevant to security practitioners
- Navigate the Linux and Windows CLI confidently
- Understand basic computing architecture (CPU, RAM, storage, networking stack)

---

## Suggested Order

1. `CIA_Triad.md` → understand the framework
2. `Ethics_and_Legal.md` → establish your ethical compass
3. `Computing_Basics.md` → build technical ground-level skills
