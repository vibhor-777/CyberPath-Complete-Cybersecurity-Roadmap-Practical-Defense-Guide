# 02 — Networking

Mastering data movement and network-level defensive controls is fundamental to cybersecurity. Attackers exploit network protocols — defenders must understand those same protocols deeply to detect and prevent attacks.

## Learning Objectives

- Explain all 7 OSI layers and identify the security threats and controls at each
- Describe the TCP three-way handshake and explain how it relates to session hijacking
- Configure basic firewall rules and understand stateful vs. stateless inspection
- Explain how DNS, DHCP, and ARP work — and how each can be abused
- Design a segmented network using VLANs and a DMZ
